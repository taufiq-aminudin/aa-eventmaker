# AA : Event Maker

Create. Celebrate. Remember.

Lightweight mobile-first web/PWA plus Android application.

## Core Architecture
User → Project → Invitation / Photo / Video / Design / AI / Guests / Location / Planner / Budget / Analytics / Memories.

The template library includes wedding concept visual starting points (garden, rustic, modern minimalist, elegant white, intimate, ballroom, adat modern, festival, monochrome, pastel, sustainable, content-friendly) and regional/cultural wedding styles (Sunda, Jawa, Bali, Minang, Asia, Middle East, Europe, Americas, Africa).

Accounts and projects are stored securely on the device. Photo/video media is stored in IndexedDB/local storage. Invitation sharing exposes public invitation details and interactive RSVP.

## Running
- Web: `npx serve web` or open `web/index.html`
- Android: Run via Android Studio or Gradle build
